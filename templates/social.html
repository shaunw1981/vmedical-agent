Connect GoHighLevel to turn this on

This tab reads your social posting activity from GoHighLevel. It needs a read-only key so it can look, but never post or change anything.

  1. In GoHighLevel, open the sub-account → Settings → Private Integrations.
  2. Create a token and tick the two read-only scopes: View Social Planner Accounts and View Social Planner Posts.
  3. Copy the token, and grab the Location ID (Settings → Business Profile, or the id in the GHL web address).
  4. Double-click open-settings.command and add:
    GHL_API_TOKEN=your-token
    GHL_LOCATIONS=Kentville=locationId (add more locations comma-separated).
  5. Double-click restart.command, then reload this page.

Heads-up on what this shows: GoHighLevel's API reports posting activity (what's been published and what's queued). Audience reach, engagement, follower counts, and Google star ratings aren't available through GoHighLevel — those need Facebook & Google connected directly, which we can scope as a later phase.
