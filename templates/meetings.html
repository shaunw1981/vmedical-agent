Connect Granola

To pull meeting notes, add a Granola workspace API key.

  1. In the Granola desktop app, create a workspace API key (starts with grn_).
  2. Add GRANOLA_API_KEY=… to .env.
  3. Make sure your two Granola folders are named to match GRANOLA_CLIENT_FOLDERS and GRANOLA_TEAM_FOLDERS (defaults: “Client Consults” and “Team Meeting”).
  4. Double-click restart.command, reload, then click Sync from Granola.
